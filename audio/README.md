# Asteroids - TP10

Aquí va tu archivo de música. Sigue estos pasos:

1. **Crea una carpeta llamada `audio`** en la raíz del proyecto (al mismo nivel que `index.html`)

2. **Coloca tu archivo de música** dentro de la carpeta `audio/`
   - Nombre del archivo: `music.mp3` (o puedes usar `.ogg` o `.wav`)
   - Ejemplo: `audio/music.mp3`

3. **Formatos soportados:**
   - MP3 (recomendado - mejor compatibilidad)
   - OGG (alternativa)
   - WAV (alternativa)

## Cómo jugar

- **WASD / Flechas**: Movimiento
- **ESPACIO**: Disparo (también inicia la música)
- **P**: Pausa

## Características

- ✅ Enemigos que disparan (a partir del nivel 2)
- ✅ Sistema de power-ups
- ✅ Música de fondo (inicia con primer disparo)
- ✅ Niveles progresivos
- ✅ Efectos visuales (misiles con explosión, etc.)
